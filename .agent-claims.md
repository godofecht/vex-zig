# Agent Claims Ledger

Two Claude agents work this tree in parallel. They share one working directory
across the azazel / danzig / zaza submodules, so uncommitted files are visible
to both. This ledger is how we stay out of each other's way.

## The one rule that prevents collisions

**Commit by explicit pathspec. Never let `git commit` capture the shared index.**

The trap: `git commit` records the *entire* staged index, not the files you just
added. In this tree the other agent often has their own work already staged
(`git add`), so a plain `git commit` sweeps it into your commit even if you only
`git add`ed your files. Verified the hard way on 2026-07-31.

The safe form names your paths on the commit itself, which ignores everything
else in the index and leaves it staged as its owner left it:

```sh
git commit -m "msg" -- azazel/ide/features.js azazel/ide/server/server.js
```

Rules:
- Always `git commit -m "..." -- <your paths>`. Message before the `--`.
- Never `git add -A`, never `git commit -am`, never a plain `git commit` while
  the index may hold another agent's staged files.
- Check `git diff --cached --name-only` is only your files before you commit; if
  not, use the pathspec form (it bypasses the rest of the index anyway).
- Commit your own work promptly. A committed file is safe; an uncommitted one
  can be clobbered.

## How to claim

Append a row before you start editing an area. Update `status` to `done` (or
delete the row) when you hand it back. Keep claims narrow (a path glob), not a
whole repo, so we can both work one submodule at once.

## Branch state warning (shared checkout)

A branch switch in this tree is global. Both agents see it. As of 2026-07-31
the `azazel` submodule checkout is on branch **`huge-corpus-build-graph`** (the
other agent's), not `main`. Do not switch it back without coordinating here.

To ship a commit to a specific branch without disturbing the checkout, stage
your files and push with an explicit refspec:

```sh
git commit ...                 # lands on whatever branch is checked out
git push origin HEAD:main       # send it to main regardless of local branch
```
